# General Git Commit Message

To keep a common format of each til, use following formats:  

* To add a til: `git commit -m "docs: Add <til title> as a/an <til category> til"`
* To update a til: `git commit -m "docs: Update til: <til title>"`

For example,  
  
* til name: `general-git-commit-message.md`
* til title: General Git Commit Message
* til category: til-workflow

The add command will be:  
`git commit -m "docs: Add General Git Commit Message as a til-workflow til"`

The update command will be:  
`git commit -m "docs: Update til: General Git Commit Message"`

The move command will be:  
`git commit -m "docs: Move til: General Git Commit Message"`

Reference: [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/)
